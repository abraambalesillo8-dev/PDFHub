# PDFHub
Web application for PDF management with freemium plans - Upload, download, and manage PDFs with flexible storage limits based on subscription tier

This commit adds a minimal working proof-of-concept Node.js + Express app that lets you upload and download PDF files locally. It's intended to get the project running quickly; from here we can add auth, DB, freemium limits, cloud storage, CI/CD, etc.

Quick start

1. Clone the repo
   git clone https://github.com/abraambalesillo8-dev/PDFHub.git
2. Install dependencies
   npm install
3. Run
   npm start
4. Open http://localhost:3000
